Forecasts every GTA VI PlayStation 5 trophy's Exophase earn rate a week after launch, as five quantiles per trophy. The model works in count space: it forecasts earners and players-tracked separately (per-trophy logit trends in log time, shrunk toward tier means, plus a damped log-linear players-tracked extrapolation), then combines them as rate = 100 * earners / players. Built by an AI agent for make.fun's "Forecast how many GTA VI players earn each trophy in week one" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
